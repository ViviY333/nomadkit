# Nomad Kit Onboarding 设计思考

## 目标

Onboarding 不是收集完整档案，而是用最少的问题建立一张“今天可用的工具首页”：当前城市、旅居阶段、签证/保险提醒和用户最关心的工具。第一轮控制在 60-90 秒，任何一步都允许稍后补全。当前版本增加两个产品配置环节，让 onboarding 与“今日 / 清单 / 城市 / 打卡”四个现有入口直接关联。

## 设计逻辑

1. **先问意图，再问数据。** 先让用户选择“正在旅居 / 准备出发 / 旅居过但暂时不出发”，用户会理解为什么需要位置、国家和日期。
2. **定位是可选增强，不是门槛。** 先用一屏说明用途和隐私，再请求系统定位；拒绝后可手动选国家/城市。不要在第一屏弹权限。
3. **用分支减少无关问题。** 正在旅居的人填当前国家/城市和入境日期；准备出发的人填下一站和预计出发时间；有历史旅居但暂无计划的人只填去过的国家和想去的地方。
4. **把“过去”变成价值。** 去过的国家用于护照/打卡和推荐相似城市，不用于制造完成率压力；允许跳过或后续从照片导入。
5. **需求采用多选，最多 3 项。** 结果直接决定首页小组件排序，选项按行动任务写：签证/停留、保险、eSIM/Wi-Fi、汇率/预算、天气/AQI、工作地点、常用药/医疗、社群/活动。
6. **来源问题是低优先级研究字段。** 放在主流程末尾，单选且可跳过，不阻断首次价值。
7. **先展示个性化结果，再做付费墙。** 付费墙必须承接刚刚生成的结果，例如“你的清迈首页已准备好”，先让用户看到免费可用内容，再说明 Pro 解锁的提醒、城市深度卡和无限历史记录。不要在权限或敏感信息前收费。
8. **护照决定规则，周期决定提醒。** 先收集护照国籍，再用目的地计算免签和可停留天数；旅居时长用于安排签证、保险、预算提醒。

## 建议流程（8+1 屏）

| 屏 | 问题 | 必填 | 结果/用途 |
| --- | --- | --- | --- |
| 0 | 欢迎 + 不卖数据/可随时修改 | 否 | 建立信任，解释 1 分钟完成 |
| 1 | 你现在处于哪种状态？ | 是 | 决定后续分支 |
| 2 | 你持哪本护照？ | 是 | 计算免签、可停留天数和签证规则 |
| 3 | 这次大概会住多久？ | 否 | 决定签证、保险和预算提醒优先级 |
| 4 | 允许获取当前定位吗？ | 否 | 自动填城市；拒绝则手动选择 |
| 5A | 当前国家/城市、入境日期、预计停留 | 正在旅居时建议填 | 签证倒计时、今日天气、时区 |
| 5B | 下一站想去哪里、预计何时出发 | 准备出发时建议填 | 出发清单、城市卡、预算 |
| 5C | 旅居过哪些国家、之后想去哪里 | 暂无计划时可选 | 足迹/护照、相似城市推荐 |
| 6 | 最需要哪些工具（最多 3） | 是 | 选中的组件直接优先展示在首页 |
| 7 | 从哪里知道 Nomad Kit？ | 否 | 渠道归因，不改变体验 |
| 8 | 你的首页已准备好 | 否 | 展示免费结果，建立付费上下文 |
| 9 | Pro 付费墙 | 否 | 免费继续；Pro 解锁高级提醒/深度城市信息 |

### 字段边界

- MVP 只收护照国籍、国家/城市、旅居阶段、入境或出发时间、兴趣工具；护照号、精确住址、收入、联系人等敏感字段不放 onboarding。
- “正在旅居”时不强迫填写入境日期，可先生成天气/汇率/工作地点，之后在签证卡里补录。
- 国家多选建议先显示热门目的地和搜索，历史国家上限不设硬上限；低保真阶段先用 8 个常见选项。
- 位置文案要明确：`仅用于显示当地工具和提醒，不会持续追踪`。系统权限拒绝后保留手动路径。

## 付费墙建议

免费层：当前城市、天气/汇率/时区、3 个核心工具、基础清单、1 个城市记录。

Pro 层：签证/保险到期提醒、城市深度卡（工作地点/医疗/联网/现金）、无限历史足迹、跨城市比较和高级通知。首轮测试建议月付 + 年付，默认突出年付但不做倒计时或假稀缺；价格和权益由真实成本验证后再定。

## 需要验证的假设

- 用户是否愿意在首次打开时选择“旅居阶段”，而不是直接浏览首页。
- 定位自动填充是否比手动选城市更快，拒绝率是否受隐私文案影响。
- “签证/保险”是否真的是前三需求，还是“联网/工作地点”更高频。
- 看到个性化首页后，用户是否能理解 Pro 付费点，而不是把所有功能都误认为收费。

## 建议埋点

`onboarding_started`、`stage_selected`、`location_prompt_shown`、`location_allowed/denied`、`destination_completed`、`needs_selected`、`source_skipped/selected`、`personalized_home_viewed`、`paywall_viewed`、`paywall_continue`、`subscription_started`。
