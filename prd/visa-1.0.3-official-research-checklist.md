# Visa 1.0.3 官方资料代办清单

> 目的：为 1.0.3 后续更新准备官方资料。本文档不是用户-facing 签证文章，不直接合并到 NomadKit 或 DigitalNomad Visa 的内容库。
>
> 核对日期：2026-08-18。每次发布前重新检查官方页面、受理领区和金额。

## 统一核对字段

- [ ] 签证/居留项目的官方名称、法律依据和最新更新时间
- [ ] 适用护照、是否接受中国大陆普通护照、受理地点/领区
- [ ] 远程工作定义：雇主、客户、收入来源是否必须在境外
- [ ] 最低收入、资金证明、收入持续时间和换算货币
- [ ] 首次有效期、单次停留、续签和累计停留上限
- [ ] 家属资格、家属是否可工作、额外收入要求
- [ ] 护照、无犯罪记录、保险、住宿、合同/雇佣证明等材料
- [ ] 申请入口、预约方式、费用、处理时间和入境后手续
- [ ] 税务、社保、当地雇佣限制和不得从事的活动
- [ ] 官方免责声明、资料有效日期和中国领区补充要求

- [ ] 核对 Tech Talent 与 Non-Tech Talent 两套职业和收入门槛
- [ ] 核对 3–12 个月、续签后最长 24 个月的表述
- [ ] 核对中国大陆申请人的材料、Letter of Good Conduct、保险和入境/离境要求
- [ ] 核对家属、费用、税务和 Peninsular Malaysia / Sarawak 差异

## 2. 印度尼西亚：E33G Remote Worker Visa

- [ ] 官方移民页面：https://www.imigrasi.go.id/wna/daftar-visa-indonesia/E33G
- [ ] 官方 eVisa FAQ：https://molina.imigrasi.go.id/front/faq/e076131c-0d39-469b-afaf-75fc66aff923
- [ ] 核对 1 年停留、入境期限、续签/转换和多次出入境规则
- [ ] 核对境外雇佣合同、最低资金证明和不得为印尼实体工作的限制
- [ ] 核对家属随行、保险、住宿、申请费用和线上申请步骤
- [ ] 单独确认中国大陆护照的入境签证要求，不把旅游免签与 E33G 混写

## 3. 意大利：Digital Nomad / Remote Worker Visa

- [ ] 官方领事说明：https://consnewyork.esteri.it/en/servizi-consolari-e-visti/servizi-per-il-cittadino-straniero/visti/visas-to-enter-italy/digital-nomad-remote-worker-visa/
- [ ] 核对 Digital Nomad（自由职业）与 Remote Worker（雇员）两条路径
- [ ] 核对高技能/学历或经验条件、收入证明、保险和住宿合同
- [ ] 核对中国大陆申请人的意大利使领馆领区、预约和文件认证要求
- [ ] 核对 D 类签证、入境后居留许可、税务居民和当地工作限制
- [ ] 不使用其他领区 PDF 的金额或材料替代中国领区要求

- [ ] 核对续签、税务居民、家属工作限制和希腊本地雇佣禁令

## 5. 阿联酋：Virtual Work Residence Visa

- [ ] 官方政府入口：https://u.ae/en/information-and-services/visa-and-emirates-id/residence-visas/residence-visa-for-working-outside-the-uae

- [ ] 核对收入、雇佣证明、医疗保险、住宿、体检和 Emirates ID 流程
- [ ] 区分联邦 ICP 与迪拜 GDRFA 的申请入口、费用和适用酋长国
- [ ] 核对家属、税务、当地工作许可和离境失效规则

## 发布前总检查

- [ ] 五国资料均由官方页面再次核对，记录 `checkedAt` 和来源 URL
- [ ] 中文表述明确区分签证、居留许可、入境许可和免签停留
- [ ] 所有金额注明币种、税前/税后和“以受理机构最新要求为准”
- [ ] 明确声明：签证资格不等于获批，也不等于税务居民资格
- [ ] 通过中国大陆普通护照视角做一次可申请性检查
